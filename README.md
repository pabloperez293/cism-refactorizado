# CISM — Rediseño Web Institucional

Este proyecto nace con el objetivo de modernizar la página web de Cultural Inglesa San Martín (CISM).
Busco desarrollar una plataforma educativa moderna, intuitiva, rápida y completamente responsive.
El frontend está construido con React, JavaScript y Vite, aplicando buenas prácticas de desarrollo.
El backend utiliza Node.js y Express para gestionar funcionalidades mediante APIs REST.
La arquitectura está organizada en componentes reutilizables, páginas, servicios y rutas independientes.
El sitio incluye cursos de inglés, capacitación empresarial, traducciones, interpretaciones y contacto.
Se incorporan animaciones suaves y un carrusel automático para mejorar la experiencia visual.
Uno de los principales objetivos es desarrollar una evaluación de nivel de inglés interactiva.
A futuro, se proyecta implementar un panel administrativo para gestionar alumnos, consultas y evaluaciones.
Este desarrollo busca ofrecer una solución escalable, mantenible y profesional, aplicando principios de código limpio.
